# openGL_FST - Build Setup with Premake5

This project uses **Premake5** to generate Visual Studio project files and manage the build process.

## Prerequisites

1. **Premake5** - Download from [premake.github.io](https://premake.github.io/)
   - Add `premake5.exe` to your system PATH or place it in the project root

2. **Visual Studio 2022** - With C++ workload installed

3. **Dependencies** (already included):
   - GLFW3
   - GLEW
   - OpenGL

## Quick Start

### Generate Project Files

**Using PowerShell:**
```powershell
./build.ps1 -Command generate
```

**Using Batch:**
```batch
build.bat generate
```

This generates `openGL_FST.sln` and Visual Studio project files.

### Build the Project

**Release Build (Optimized):**
```powershell
./build.ps1 -Command build
```

**Debug Build (With debugging symbols):**
```powershell
./build.ps1 -Command debug
```

**Batch equivalent:**
```batch
build.bat build
REM or
build.bat debug
```

### Clean Build Artifacts

```powershell
./build.ps1 -Command clean
```

```batch
build.bat clean
```

### Rebuild Everything

```powershell
./build.ps1 -Command rebuild
```

```batch
build.bat rebuild
```

## Configuration Details

The `premake5.lua` file defines:

- **Workspace:** openGL_FST
- **Language:** C++20
- **Platforms:** x64
- **Configurations:** Debug, Release
- **Project Type:** Console Application
- **Dependencies:** GLFW3, GLEW, OpenGL32

### Debug Configuration
- Optimization: Off
- Symbols: On
- Runtime: Dynamic (/MDd)
- Preprocessor: `GLEW_STATIC`, `_DEBUG`, `_CONSOLE`

### Release Configuration
- Optimization: On
- Symbols: On (for debugging Release builds)
- Runtime: Dynamic (/MD)
- Preprocessor: `GLEW_STATIC`, `NDEBUG`, `_CONSOLE`

## Debugging with Visual Studio

1. Generate the project: `./build.ps1 -Command generate`
2. Open `openGL_FST.sln` in Visual Studio
3. Set breakpoints in your code
4. Press **F5** to debug (Release build with debug info)

## Troubleshooting

### "Cannot find premake5"
- Download Premake5 from [premake.github.io](https://premake.github.io/)
- Add to PATH or place `premake5.exe` in the project root

### Build fails with unresolved symbols
- Verify GLFW and GLEW libraries are in: `openGl/dependance/GLFW/lib-vc2026` and `openGl/dependance/GLEW/lib/Release/x64`
- Check that Visual Studio C++ tools are installed

### Breakpoints not working
- Use **Release** build: it has debug information enabled
- Ensure `.pdb` files are generated in the output directory

## Additional Commands

You can also use MSBuild directly:

```batch
REM Build Release
msbuild openGL_FST.sln /p:Configuration=Release /p:Platform=x64

REM Build Debug
msbuild openGL_FST.sln /p:Configuration=Debug /p:Platform=x64

REM Clean
msbuild openGL_FST.sln /t:Clean /p:Configuration=Release /p:Platform=x64
```
